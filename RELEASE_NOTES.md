## v0.1.1 — long-running MCP tools

This experimental, **unofficial and independently maintained** Magpie/OpenCode provider now configures the generated `magpie` MCP server with a 30-minute (1,800,000 ms) tool timeout instead of inheriting the native five-minute cutoff. This targets an observed 300-second abort of a long `Bash` tool, followed by orphaned results and HTTP 409. The change is scoped to the private generated MCP server; it does not edit user-wide Claude Code timeout settings or unrelated MCP servers.

A regression test checks the MCP server timeout and preserved helper arguments. Go test and `go vet` run in the release build before the eight binaries and SHA-256 checksum manifest are generated by GitHub Actions. The earlier `v0.1.0` tag and binaries remain unchanged.

**No guarantee that a tool will run for 30 minutes:** frontend cancellations, client disconnects, server failures and other boundaries can end it early. A failed `Bash` or `Edit` may already have modified files. Verify effects before retrying.

**Security and policy:** This is third-party, unreviewed software, not supported by Magpie or Anthropic. It runs an authenticated Claude Code TUI, can modify Claude trust and hooks, and may enable bypass-permissions in its working directory. Subscription account/terms risks remain. See the [security documentation](https://github.com/Guuuu233/magpie-claude-tui-plugin#exact-security-and-configuration-effects).
